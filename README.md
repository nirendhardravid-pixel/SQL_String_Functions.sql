## SQL String Functions

This section contains SQL string functions used to manipulate and process text data.

### Topics Covered

* UPPER() – Converts text to uppercase.
* LOWER() – Converts text to lowercase.
* LENGTH() – Returns the length of a string.
* CONCAT() – Combines two or more strings.
* SUBSTRING() – Extracts part of a string.
* TRIM() – Removes leading and trailing spaces.
* REPLACE() – Replaces specified text.
* LEFT() – Extracts characters from the left.
* RIGHT() – Extracts characters from the right.

### Objective

To practice SQL string functions for text manipulation and data cleaning.
